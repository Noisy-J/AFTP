## 📋 О программе

**AFTP** - это полнофункциональный FTP клиент, написанный на C++ без внешних зависимостей. Программа поддерживает все основные операции FTP, включая рекурсивную загрузку и скачивание папок, управление профилями, историю действий и цветной консольный интерфейс.

### Ключевые особенности:
- ✅ **Рекурсивная загрузка/скачивание папок** - основная "фишка" клиента
- 👤 **Управление профилями** - сохраняйте настройки подключений
- 📁 **Полная поддержка FTP команд** - просмотр, навигация, удаление, переименование
- 🎨 **Цветной интерфейс** - интуитивно понятная подсветка
- 📜 **История действий** - все операции сохраняются
- 🚀 **Автономность** - не требует внешних библиотек или программ

## 🎮 Управление

### Основные команды:

| Клавиша | Действие |
|---------|----------|
| `↑` `↓` | Навигация по списку файлов |
| `Enter` | Открыть папку |
| `Backspace` | Назад (родительская папка) |
| `D` | Скачать (файл или папку) |
| `U` | Загрузить (с выбором типа) |
| `T` | Удалить файл/папку |
| `C` | Создать папку |
| `N` | Переименовать |
| `I` | Информация о файле |
| `R` | Обновить список |
| `F` | Отключиться от сервера |
| `H` | Показать историю |
| `Q` | Выход |

### Меню профилей:
| Клавиша | Действие |
|---------|----------|
| `↑` `↓` | Выбор профиля |
| `Enter` | Подключиться |
| `N` | Создать новый профиль |
| `D` | Удалить профиль |
| `Esc` | Отмена |

### Создание/редактирование профиля:
| Клавиша | Действие |
|---------|----------|
| `↑` `↓` | Переключение между полями |
| `Enter` | Подтвердить поле и перейти дальше |
| `Tab` | Показать/скрыть пароль |
| `Backspace` | Очистить поле |
| `Esc` | Отмена |

## 📥 Установка

### Предварительные требования:
- Windows 7/8/10/11
- Visual Studio 2019/2022 или MinGW-w64

### Скачивание:
```bash
git clone https://github.com/noiys-j/aftp.git
cd aftp
```

### Компиляция:

#### Visual Studio (рекомендуется):
```cmd
# Откройте проект в Visual Studio
# Выберите Release x64
# Нажмите Ctrl+Shift+B для сборки
```

#### Или через командную строку:
```cmd
cl /EHsc /std:c++17 aftp.cpp ws2_32.lib
```

#### MinGW:
```bash
g++ -std=c++17 aftp.cpp -o aftp.exe -lws2_32 -static
```

## 🖥️ Использование

### Быстрый старт:

1. **Запустите программу:**
   ```cmd
   aftp.exe
   ```

2. **Подключитесь к серверу:**
   - Нажмите `Enter` для выбора/создания профиля
   - Заполните данные подключения:
     - Название (любое)
     - Сервер (например, ftp.example.com)
     - Порт (обычно 21)
     - Логин
     - Пароль

3. **Навигация:**
   - Используйте стрелки для перемещения
   - `Enter` для открытия папок
   - `Backspace` для возврата назад

4. **Скачивание:**
   - Выберите файл или папку
   - Нажмите `D` - клиент сам определит тип

5. **Загрузка:**
   - Нажмите `U`
   - Выберите `F` (файл) или `D` (папка)
   - Укажите путь к локальному файлу/папке

### Пример работы с папками:

```bash
# Скачивание всей папки рекурсивно:
1. Выберите папку в списке
2. Нажмите D
3. Укажите локальный путь (Enter для имени папки)
4. Программа скачает все подпапки и файлы

# Вывод в консоли:
[СОЗДАНА] ./images
  [ПАПКА] thumbnails
    [ФАЙЛ] thumb1.jpg ... OK
    [ФАЙЛ] thumb2.jpg ... OK
  [ФАЙЛ] image1.jpg ... OK
  [ФАЙЛ] image2.jpg ... OK
  [ИТОГО] Папок: 1, Файлов: 4
```

## ⚙️ Конфигурация

### Файлы данных:

**ftp_profiles.dat** - сохраненные профили:
```ini
[PROFILE]
NAME=Мой сайт
SERVER=ftp.example.com
PORT=21
USERNAME=myuser

```

```

[Wed Jan 15 12:32:15 2026] Скачана папка images
```

## 🛠️ Сборка из исходников

### Зависимости:
- Windows SDK
- Winsock2 (встроен в Windows)

### Пошаговая сборка:

1. **Установите Visual Studio:**
   - Скачайте Visual Studio Community (бесплатно)
   - Установите "Разработка классических приложений на C++"

2. **Клонируйте репозиторий:**
   ```cmd
   git clone https://github.com/noisy-j/aftp.git
   cd aftp
   ```

3. **Создайте проект:**
   - Откройте Visual Studio
   - Создайте новый проект "Консольное приложение C++"
   - Скопируйте содержимое ftp_client.cpp в основной файл

4. **Скомпилируйте:**
   - Выберите конфигурацию "Release" и "x64"
   - Нажмите `Ctrl+Shift+B`

5. **Запустите:**
   - Файл будет в `Release/aftp.exe`
   - Скопируйте его в удобное место

## 🐛 Известные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Не подключается к серверу | Проверьте порт (обычно 21). Убедитесь, что сервер поддерживает пассивный режим (PASV) |
| Не отображаются файлы/папки | Некоторые FTP серверы возвращают LIST в другом формате. Попробуйте другой сервер |
| Ошибка компиляции | Убедитесь, что используется C++17 и подключена библиотека ws2_32 |
| Не скачиваются русские имена | Программа использует кодировку Windows-1251 |
